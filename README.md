# Docker Todo Application

A full-stack Todo application built using Node.js, Express, Flask, SQLite, Docker and Docker Compose.

## Architecture

The application consists of two services:

### Frontend

- Node.js
- Express
- HTML
- CSS
- JavaScript
- Port 3000

### Backend

- Python
- Flask
- SQLite
- Port 5000

## Features

- Add Todo
- View Todos
- Mark Todo as completed
- Delete Todo

## Running with Docker Compose

```bash
docker compose build
docker compose up
